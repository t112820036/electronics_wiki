MODULE 0 · LINT 增補前置基礎

電學基礎三要素：看懂電路的水流直覺

💡 一句話秒懂：把電路想像成「水塔與水管系統」——電壓 (V) 是水壓高度差，電流 (I) 是水管裡的水流量，電阻 (R) 則是水管狹窄造成的阻力。

三大物理量與歐姆定律

  • 電壓 Voltage (V，伏特 V)：推動電荷移動的能量差（水壓）。
  • 電流 Current (I，安培 A)：每秒流過導線截面的電荷量（水流量）。
  • 電阻 Resistance (R，歐姆 Ω)：材料阻礙電流的能力（水管阻力）。
歐姆定律：V = I × R  |  電功率：P = V × I
⚠️ 常見迷思：「電壓高就一定會電傷人？」
真正造成灼傷與生理危害的是流過心臟的電流 (I)，但需要足夠高的電壓 (V) 才能突破皮膚電阻 (R)。

🎛️ 互動實驗室：歐姆定律即時計算器

拖動滑桿調整電源電壓與限流電阻，觀察電流與消耗功率變化：

流過電流 I = V / R
20.0 mA
消耗功率 P = V × I
180.0 mW

模組 0：前置基礎
MODULE 1A · 波形與信號基礎

電信號的語言：正弦波與非正弦波

🌊 正弦波（Sine Wave）四大振幅指標

  • 峰值 (Vp) 與 峰對峰值 (Vpp = 2Vp)：波浪的最大高度。
  • 有效值 (Vrms = Vp / √2)：產生相同熱功率的等效直流電壓。
  • 家用市電真相：插座標示 110V 是 Vrms，實際波峰高達 155.6V！

⏱️ 非正弦波（方波 / 三角波 / 脈波）時間參數

  • 週期 (T) 與頻率 (f)：重複一次的時間與每秒次數（f = 1 / T）。
  • 責任週期 (Duty Cycle)：高電位時間佔整個週期的百分比：
Duty Cycle = (Ton / T) × 100%

廣泛用於數位時脈（Clock）與 PWM 馬達調速、LED 調光。

MODULE 1B · 半導體與電源轉換

從交流到平穩直流：P-N 接面與整流濾波

1. P-N 接面單向收費站

P 型（多數載子：電洞）與 N 型（多數載子：電子）結合形成空乏區與障壁電壓：

  • 矽 (Si)：約 0.7V；鍺 (Ge)：約 0.3V。
  • 順向偏壓：大於門檻即導通。
  • 逆向偏壓：空乏區變寬、截止阻擋。

2. 特殊二極體家族

  • 稽納二極體 (Zener)：刻意操作於逆向崩潰區做直流穩壓（須串聯限流電阻並檢核最大功率 PZM）。
  • 發光二極體 (LED)：電能轉光能，順向壓降較高（約 1.8V ~ 3.3V）。

3. 電容濾波與漣波因數

整流後的脈動直流透過並聯電容充放電填平波谷，降低漣波因數：

r = Vr(rms) / Vdc

r 越小，代表直流電越接近一條平穩直線。

整流電路架構 二極體數量 變壓器需求 輸出直流平均值 (Vdc) 輸出漣波頻率 導通壓降損耗
半波整流 1 顆 一般變壓器 ≈ 0.318 Vp(out) 1 × fin 1 顆 (0.7V)
全波整流（中心抽頭） 2 顆 需中心抽頭變壓器 ≈ 0.636 Vp(out) 2 × fin 1 顆 (0.7V)
橋式整流（最常用） 4 顆 一般變壓器 ≈ 0.636 Vp(out) 2 × fin 2 顆 (1.4V)

模組 1：二極體與整流
MODULE 2 · BJT 電流控制放大器

用小手轉動大水閥：BJT 工作區間與放大組態

🎛️ 電流控制與三大工作區間

BJT 為電流控制元件（IE = IB + IC），用微弱基極電流 IB 控制集極大電流 IC：

  • 工作區 (Active)：B-E 順向、B-C 逆向 → IC = βIB（線性放大）。
  • 飽和區 (Saturation)：兩接面皆順向 → 數位開關 ON。
  • 截止區 (Cutoff)：兩接面皆逆向 → 數位開關 OFF。

⚖️ 直流偏壓與 Q 點穩定

如同「把鞦韆架在正中央」，分壓式偏壓搭配射極負回授電阻 RE 可穩定靜態工作點（Q 點）於交流負載線中央：

  • 防止正負半週撞牆造成截波失真（Clipping）。
  • 抑制溫度升高導致電流暴衝的熱失控（Thermal Runaway）。
  • 多級串級：RC 耦合隔直通交（低頻受限）；直接耦合可放大直流（須克服準位飄移）。
BJT 單級組態 電壓增益 (Av) 電流增益 (Ai) 輸入/輸出相位 輸入 / 輸出阻抗 核心工程角色
共射極 (CE) 高 高 (≈ β) 反相 (180°) 中等 / 中高 主力電壓與功率放大級
共集極 (CC / 射極隨耦器) 略小於 1 高 (≈ β+1) 同相 (0°) 極高 / 極低 緩衝級 (Buffer) 與阻抗匹配
共基極 (CB) 高 略小於 1 (α < 1) 同相 (0°) 極低 / 高 高頻射頻（RF）放大級

MODULE 3 · MOSFET 電壓控制放大器

隔空感應的靜電水閘：MOSFET 與疊接架構

⚡ 電壓控制與平方律特性

  • 極高輸入阻抗：閘極隔著二氧化矽（SiO2）絕緣層，直流電流 IG ≈ 0，純靠電壓產生電場控制通道。
  • 增強型 (E-MOSFET) 須超過臨界電壓 Vt 才建立通道（另有預植通道的空乏型 D-MOSFET）。
  • 飽和區（夾止區）線性放大公式：
ID = k (VGS − Vt)2

偏壓常採分壓偏壓（無負載效應）或汲極回授偏壓（強制 VGS = VDS 鎖定飽和區）。

🚀 單級對照與疊接放大器 (Cascode)

  • 單級組態完美對應 BJT：共源極 (CS ↔ CE 主放大)、共汲極 (CD 源極隨耦器 ↔ CC 緩衝)、共閘極 (CG ↔ CB 高頻)。
  • 疊接架構 (Cascode = CS 串接 CG)：在 CS 上方疊加 CG，釘住 CS 汲極電壓波動，大幅抑制寄生電容引發的密勒效應（Miller Effect），展延高頻頻寬！
  • 直接耦合：現代類比積體電路（IC）的核心連接方式。
🚨 初學者頭號陷阱：「BJT 飽和區」vs.「MOSFET 飽和區」完全相反！
• BJT 飽和區 = 電流塞滿、壓降極小 → 用作數位開關 ON。
• MOSFET 飽和區（夾止區） = 通道夾止、電流穩定受控於 VGS → 用作類比線性放大！

MODULE 4 · 從類比邁向數位 VLSI

一開一關的互補雙閘門：CMOS 反相器與邏輯閘

🔄 CMOS 互補原理與對偶規則

  • 互補架構：上方 PMOS（上拉網路） + 下方 NMOS（下拉網路）。穩態時必有一顆截止，因此靜態功耗趨近於零、具備滿擺幅輸出（0V 至 VDD）與高雜訊邊限。
  • 互補對偶原則：PMOS 與 NMOS 的串並聯結構必定相反：
    • 反及閘 (NAND)：上方 PMOS 並聯、下方 NMOS 串聯（4 顆電晶體）。
    • 反或閘 (NOR)：上方 PMOS 串聯、下方 NMOS 並聯（4 顆電晶體）。
  • VLSI 擴充：NAND / NOR 後方加一級反相器即構成 AND / OR 閘，進而建構數十億電晶體的 CPU。

MODULE 5A · 運算放大器線性應用

超自律的自動平衡天平：理想 OPA 與負回授

🏛️ 理想 OPA 與負回授兩大黃金法則

理想 OPA 具備無限大開迴路增益、無限大輸入阻抗與零輸出阻抗。當接入負回授時，自動成立兩大法則：

1. 虛短路 (Virtual Short)：V+ ≈ V− 2. 虛斷路 (Virtual Open)：I+ = I− ≈ 0

註：虛短路是指兩輸入端電位相等，並非真的用導線接在一起，且僅在負回授時成立！

🧮 五大經典線性運算電路

電路名稱 增益 / 運算功能 相位與特性
反相放大器 Av = −Rf / Ri 輸出與輸入反相 180°
非反相放大器 Av = 1 + (Rf / Ri) 同相輸出、輸入阻抗極高
加法器 / 減法器 多訊號加權總和 / 差值 音訊混音、消除共模雜訊
積分器 / 微分器 將電阻替換為電容 實現波形微積分（方波→三角波）

MODULE 5B · 非線性應用與頻率篩選

抗雜訊開關、自給自足節拍器與智慧濾波器

1. 比較器與施密特觸發器

  • 開迴路比較器：操作於飽和區，比較 V+ 與 V− 將類比電壓轉成數位高低準位。
  • 施密特觸發器 (Schmitt Trigger)：引入正回授產生磁滯現象，擁有上下雙臨界電壓（VUT, VLT），徹底消除雜訊造成的誤觸發。

2. 波形產生器（振盪器）

  • 正弦波振盪器：須滿足巴克豪森準則（迴路增益 |Aβ| = 1 且總相移 0° 或 360°），如韋恩電橋（Wien-Bridge）與 RC 相移振盪器。
  • 方波 → 三角波：無穩態多諧振盪器利用 RC 充放電產生方波，再串接積分器即輸出三角波。

3. 主動濾波器 (LPF / HPF)

結合 OPA + RC 網路（免用笨重電感），構成一階低通（LPF）與高通（HPF）濾波器：

fc = 1 / (2πRC)

在截止頻率 fc 處增益下降 −3dB（振幅為 0.707 倍），超過後平滑衰減而非一刀切斷。
